# Flowy — магазин цветов на WordPress

WordPress + Astra (дочерняя тема Flowy) + Elementor + WooCommerce, только бесплатные плагины.
Проверено локально: WordPress 7.1, WooCommerce 11.1, Elementor 4.3, PHP 8.4, MariaDB.

## Что внутри

- `theme/flowy/` — дочерняя тема (она же в архиве `dist/flowy-theme.zip`):
  - своя шапка с корзиной (счётчик обновляется без перезагрузки) и подвал с контактами;
  - каталог: фильтр по категории и цене, сортировка (популярные, новинки, по цене), «В корзину» прямо из сетки;
  - товар: размер, упаковка, кашпо, открытка с текстом — с пересчётом цены, кнопки «В корзину» и «Купить сейчас»;
  - оформление: имя, телефон, почта, адрес (только для курьера), дата и интервал доставки, курьер / бесплатно от 5 000 ₽ / самовывоз;
  - дата и время доставки в письмах, админке и на странице «Спасибо»;
  - Яндекс.Метрика и контакты магазина — в «Настройки → Общие».
- `setup/setup.php` — настройка всего магазина одной командой (WooCommerce, ЧПУ `/catalog/…`, доставка, оплата, категории, 12 товаров с фото, главная в Elementor, SEO-заголовки Yoast). Запускать можно повторно.

## Установка на хостинг заказчика (PHP 8.0+, MySQL 5.7+)

1. Установить WordPress (русская версия).
2. Плагины: WooCommerce, Elementor, Yoast SEO, WP Mail SMTP, ЮKassa (yookassa), кеширование — WP Super Cache или LiteSpeed Cache, если хостинг на LiteSpeed.
3. Тема Astra, затем загрузить `dist/flowy-theme.zip` («Внешний вид → Темы → Добавить»).
4. С SSH-доступом: `wp eval-file setup.php /путь/к/фото` — всё остальное настроится само.
   Без SSH: перенести готовый сайт плагином All-in-One WP Migration (экспорт из тестовой копии → импорт на хостинге).
5. Заполнить то, что даёт заказчик:
   - «Настройки → Общие → Flowy»: телефон, почта, адрес, часы, номер счётчика Метрики;
   - WP Mail SMTP: данные почтового ящика;
   - WooCommerce → Настройки → Платежи → ЮKassa: shopId и секретный ключ тестового магазина;
   - «Настройки → Постоянные ссылки» → «Сохранить» (обновить ЧПУ после переноса);
   - включить кеширование в плагине кеша.
6. Заменить фото и тексты товаров на свои (фото сейчас с Unsplash для примера).

## Проверено

- заказ проходит от «В корзину» в каталоге до страницы «Спасибо», письма уходят магазину и покупателю с опциями, датой и интервалом;
- цена пересчитывается по опциям (например, большой букет + открытка = 7 250 ₽);
- бесплатная доставка от 5 000 ₽ скрывает платного курьера, при самовывозе адрес не нужен;
- `/sitemap_index.xml` и `/robots.txt` отдаются, корзина и оформление закрыты от индексации;
- без горизонтального скролла на ширине 375 px.
