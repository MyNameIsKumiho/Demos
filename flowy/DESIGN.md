# DESIGN.md — Flowy, магазин цветов

Рамки для макета и будущей темы WordPress/Elementor. Любой экран сверяется с этим файлом
и с каталогом `.claude/skills/design-anti-slop/references/catalog.md`.

## Идея

Бриф: «тёплый домашний уют», композиция из блоков, объём, без плотного текста и лишней
анимации. Тепло даёт розово-молочный фон и цветные блоки (пудра, шалфей, песок). Объём дают
крупные фото букетов, а не тени у карточек. В демо фото с Unsplash (лицензия Unsplash), на сайте — фото заказчика. Акцент — цвет садовой
розы, только на главных действиях.

Сайт светлый по брифу, тёмной темы нет (решение, а не пропуск).

## Палитра (токены)

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#F8EEE6` | фон страницы |
| `--surface` | `#FFF8F2` | карточки, поля |
| `--blush` | `#F1D9D3` | блок «пудра» |
| `--sage` | `#DEE4D2` | блок «шалфей» |
| `--sand` | `#EFE0CA` | блок «песок» |
| `--ink` | `#3A2A28` | основной текст |
| `--ink-2` | `#6B5552` | вторичный текст |
| `--line` | `#E4CFC4` | границы |
| `--line-strong` | `#C9ADA2` | границы контролов |
| `--accent` | `#8E2F45` | главные действия: «Выбрать букет», «В корзину» на товаре, «Оформить заказ» |
| `--good` | `#4F6B3F` | подтверждения |
| `--bad` | `#A8352B` | ошибки формы |

Акцент — максимум 2 видимых применения на экран. Кнопки «В корзину» в сетке каталога
вторичные (контур), иначе акцент размазывается по всей сетке.

## Шрифты

- Display: **Montserrat Alternates** 600 — логотип, заголовки блоков, цены крупно.
- Body: **Nunito** 400/600/700 — всё остальное. Body 16px, line-height 1.55.
- Шкала: 13 / 14 / 16 / 18 / 22 / 30 / 44.

## Форма

- Радиусы: блоки 24px, карточки 18px, контролы 12px.
- Высоты контролов: 44 (default), 36 (compact). Контролы в одном ряду — одной высоты.
- Теней нет. Объект отделяется цветом блока или бордером.
- Движение: только смена фона/бордера на hover и сдвиг кнопки на 1px при нажатии.

## Запреты

indigo/violet и градиентный текст; эмодзи в интерфейсе; капс-лейблы; пастельные
статус-пилюли; `transition-all`, `hover:scale`, анимации появления секций; цветная полоска
слева у карточек; подчёркнутые кнопки; штампы в текстах («с любовью», «уникальный»,
«качественно и в срок»).
